### 1.1.1 −z（回 3）の 1 周期の差分の見積もり（計算）

回 3（−z、入力 0.3）は、回 5 の記録（+z、入力 1.0）と**同じ姿勢 T で、Jacobian もほぼ同じ**として見積もる。Servo の差は入力に比例する（`scaleCartesianCommand`: `linear_scale × publish_period × twist`。`servo_calcs.cpp:999-1001`）。符号は反転、大きさは 0.3 倍:

| 関節 | 回 5（+z 1.0）の定常の差 [tick] | 回 3（−z 0.3）の見積もり [tick] | `lround` の後 |
|---|---|---|---|
| lift | −0.28 | +0.08 | 0 |
| elbow | −1.41 | +0.42 | 0（0.5 未満） |
| wrist_flex | +1.69 | −0.51 | −1 か 0（0.5 の境目。測定値 → rad の端数で決まる） |
| pan・roll | 0 | 0 | 0 |

- **[事実]** 測定位置は整数 tick の値（rad に変換したもの）で、ドライバは目標を `lround`（`calibration.cpp:152-155`）で整数にするので、**差の大きさが 0.5 tick 未満の関節は、目標が測定位置と同じ tick になる**。回 3 は lift・elbow が 0、wrist_flex が境目。**回 3 では、サーボに伝わった目標の変化が 0〜1 tick**で、「動かなかった」ことは、**量子化で消えた可能性が高く、閉じる向きの結果としては結論にならない**（11 章の推測の検証にならない）。
- 平滑化で、最初の 4 周期は、定常の 0.40・0.88・0.98・1.0 倍に立ち上がる（6.1 の A4b）ので、1 秒（約 30 周期）の定常は 26 周期。見積もりは定常の値。
- **回 5 の +z 1.0（`--allow-fast`）の値は、`lround` の後、lift 0、elbow −1、wrist_flex +2 tick。** これは 0.5 tick を超えており、「目標は測定から 1〜2 tick 離れていたが、動かなかった」と言える（**上限の入力 1.0 でも動かなかったと言えるのは、+z（重力に逆らう向き）だけ**）。回 2・回 4 は同じ向きの +z（0.5・1.0）で 0 mm。

### 6.2 A4: 重力の向き（URDF の質量・重心から計算。T は W1 の実測の関節角）
