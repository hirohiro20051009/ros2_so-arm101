# 実機の精度の測定の計画（D-2 ＋ 接近方向の統一の前段）

> **【保留（2026-11-13、ユーザーの方針の変更）】** Servo を積算方式で使えるようにする方向を検討する（`docs/diffik_accumulate_plan.md`）。この計画と、絶対目標の道具の話は、いったん保留。後で「MoveIt だけで、2〜3 姿勢 × 各 3 回、先端 ±3 mm」の簡単な形に書き直す予定。内容は書き直しの材料として残す。

作成: 2026-11-13。**計画だけ。実装・モック・実機・ビルド・シリアルポートを開く操作はしていない。** 実行（実機の操作）はユーザーだけ。コードの変更はしない。
決定（ユーザー、2026-11-13）: 見直しの方向は **D-2 ＋ 接近方向の統一**。まず実機の精度を測る。D-1 はその結果を見て判断、D-3（EEPROM の書き込み）は最後。Servo 一式は方向が決まるまで残す。依存の監査は Servo の方向が決まってから。D14 は保留。
背景と用語: `docs/servo_w3_investigation_plan.md`（1.1・6.2）。**開く向き = 自重に逆らう向き**（T で elbow・lift は −。重力は + 向き。URDF の質量・重心からの計算）。W1 の実測: T への到達で elbow は 17 tick 手前、lift は 2 tick 行き過ぎ、wrist_flex は 2 tick 手前（1 サンプルだけ）。

## 1. 何を測るか（問い）

| 問い | 測り方 | 判断に使う先 |
|---|---|---|
| **Q-A 手前止まりの量**: 同じ目標へ、開く向き・閉じる向きから近づいたとき、止まる位置は目標からどれだけ離れるか（関節ごと、tick） | A 系列 | D-2 の補償量。D-1・D-3 の要否 |
| **Q-B 再現性**: 同じ向きから繰り返したときの、止まる位置のばらつき（関節 tick、先端 mm） | A 系列（N 回） | 補償で詰められる限界（ばらつき以下には詰められない） |
| **Q-C 向きによる差（ヒステリシス）**: 開く向きと閉じる向きの止まる位置の差 | A 系列の比較 | 接近方向の統一の効果 |
| **Q-D 詰められる範囲**: 手前止まりを見込んだ目標（ずらした目標）で、どこまで目標に近づけられるか | B 系列 | D-2 ＋ 接近方向の統一の実力 |
| **Q-E 静止後のクリープ**: 止まった後に位置が動くか | 各到達の 5 秒後・15 秒後 | 測定のタイミングの決め方 |

判定の基準は**初回は置かない**（記録だけ。W3 と同じ）。参考の目安（ユーザーが見直す）: 関節 3 tick（0.0046 rad）以内。elbow では先端で約 0.6 mm（elbow の dz/dq = −124 mm/rad。計算）。

## 2. 道具と範囲（**既存だけ。コードの変更なし**）

- 起動: `ros2 launch so_arm101_bringup bringup.launch.py mock:=false read_only:=false use_servo:=false torque_limit:=500`（**`use_servo:=false`**。Servo・forward controller は起動しない。W1 と同じ RViz あり。ログは `~/so_arm101_check/acc_<段階>.log` へ `tee -i`。**launch は前景で**）。
- 動かす: **MoveIt（OMPL、Velocity・Acceleration Scaling 0.1。Pilz は使わない）** と **`tools/send_joint_delta.py`**（1 関節の相対。|delta| ≤ 0.5 rad、速度 ≤ 0.1 rad/s）。
- 読む: `ros2 topic echo /joint_states --once --field position`、`ros2 run tf2_ros tf2_echo base_link gripper_frame_link`、コマンド A（止まっていることの確認。`servo_real_check.md`）。
- **先端の位置の分解能**: `tf2_echo` は **1 mm 刻み**（W1 の報告 `(0.172, 0.000, 0.055)`）。**先端の変位は、記録した関節角から、URDF の順運動学で計算する**（Claude が、記録を受け取ってから、リポジトリの外の計算で行う。**順運動学は T の実測（pan +0.0031、lift −0.3813、elbow +0.5501、wrist_flex +1.4454、roll −0.0069）で (0.1724, −0.0004, 0.0552) m となり、tf の実測 (0.172, 0.000, 0.055) と 0.2 mm 以内で一致した（事実。計算と W1 の実測）**）。tf は、ユーザーが各姿勢で 1 回読んで突き合わせる。
- **床からの高さは、TCP（指先の間）基準で、ユーザーが測る**（定規。M1）。関節 tick の換算は 1 tick = 2π/4095 = 0.001534 rad。

## 3. 姿勢（すべて 5 関節を整数の度で指定する）

MoveIt の Joints タブのスライダーは整数の度で、動かしていない関節も最大 0.5° 動く（`feetech_write_check.md` W4 の事実）。**毎回、5 関節すべてを下の表の値にする**（目標の姿勢が絶対値で一定になる）。

| 姿勢 | pan | lift | elbow | wrist_flex | roll | 先端 z（順運動学。mm） | 用途 |
|---|---|---|---|---|---|---|---|
| **G（目標。= T）** | 0 | −22 | +30 | +83 | 0 | 58.8（実測の T は 55.2。elbow の手前止まりの分） | 近づく先 |
| E+（elbow の開く向きの接近の出発点） | 0 | −22 | +33 | +83 | 0 | 52.5 | G へ **−** に動く（= 開く向き）で近づく |
| E−（elbow の閉じる向きの接近の出発点） | 0 | −22 | +27 | +83 | 0 | 65.5 | G へ **+** に動く（= 閉じる向き）で近づく |
| L+ / L− | 0 | −19 / −25 | +30 | +83 | 0 | 53.2 / 64.5 | lift の同様（L+ から − に動くのが開く向き） |
| W+ / W− | 0 | −22 | +30 | +86 / +80 | 0 | 59.5 / 約 58 | wrist_flex（T で重力はほぼ 0。向きは符号だけで区別） |

**床の制限（引き継ぎ。`servo_real_check.md`）**: tf の先端 z ≥ 0.045 m、T からの正味の下がり 10 mm 以内（T の実測 z 0.055 なので、どちらも先端 z ≥ 0.045 m）。**この計画の追加の規則**: ① どの出発点・ずらした目標も、**順運動学の z ≥ 0.050 m**（手前止まりで約 5 mm 低くなる余裕。elbow 27 tick × 124 mm/rad ≒ 5 mm）。② **この規則のため、lift・elbow の + 側は ±3° まで**（±5° は 49.6／48.7 mm で不可。− 側は 5° でも可）。③ 各到達の後、tf の z が **0.048 m を下回ったら中止して上げる**（開く向きに send_joint_delta で）。**lift・elbow が + に動くと先端は下がる**（dz/dq = −107・−124 mm/rad。計算）ので、**+ に動く指令は、毎回、先に順運動学の z を確認する**（Claude が事前に計算して表にする）。

## 4. 実験

### A 系列: 同じ絶対目標 G に、同じ向きから近づく（MoveIt。**まず elbow だけ**）

1 回の「到達」= 出発点（E+ または E−）に MoveIt で出る → **止まっていることの確認（コマンド A）→ 5 秒待つ** → MoveIt で G へ（OMPL、Scaling 0.1）→ **コマンド A → 5 秒後・15 秒後に関節角を 3 回ずつ読む**（1 秒おき。tick の揺れも見る）→ tf を 1 回。記録は 1 到達 1 ブロック。

| 段 | 内容 | 回数 |
|---|---|---|
| A1 | elbow: **開く向き（E+ → G）** | 5 回 |
| A2 | elbow: **閉じる向き（E− → G）** | 5 回 |
| A3 | lift、A4: wrist_flex（それぞれ開く・閉じる） | 各 3 回ずつ。**A1・A2 の結果を見てから**（elbow で手前止まりが小さければ省略） |

- 順序: **O C C O O C C O O C**（交互の ABBA。温度・時間の影響を偏らせない）。出発点への移動（E+ へ行くとき elbow は + 向き = 自重の向きで正確、E− へ行くときは開く向きで手前止まり）は、**G から出発点への移動も記録する**（Q-C の材料になる）。
- 1 到達 約 2 分、A1・A2 で 約 40 分。**30 分ごとに停止して休む**（サーボの温度。触って熱くないこと）。
- 記録するもの（各到達）: 出発点の実測、G の実測（5 関節。3 回）、G との差（rad と tick）、tf（1 回）、5 秒後・15 秒後の差、`step limit`・`FAULT` の有無。

### B 系列: 手前止まりを見込んだ目標で、どこまで詰められるか（`send_joint_delta.py`。**A の結果を見てから、ユーザーと計画を確認して実行**）

`send_joint_delta.py` は「今の実測 + delta」を JTC の目標にする。細かい値（0.001 rad）を指定できる。**1° = 11 tick なので、MoveIt の整数の度では細かい補正ができない**（B 系列で `send_joint_delta.py` を使う理由）。

| 段 | やり方 | 試すこと |
|---|---|---|
| B1 | 開く向きで E+ → G に到達 → 実測 m を読む → 誤差 e = m − G_elbow（rad）→ `send_joint_delta.py elbow <−k·e> --seconds <≥ \|k·e\|/0.1>`、k = 1、1.5、2（各 3 回） | **開く向きに、見込みの k 倍の目標を出すと、どこまで詰められるか**（k = 1 は「測った誤差だけ戻す」） |
| B2（接近方向の統一） | G に到達 → `send_joint_delta.py elbow -0.04 --seconds 4`（いったん開く。先端は上がる向き）→ 止まるのを待って実測 m2 → delta = (G_elbow − m2) + b → `send_joint_delta.py elbow <delta> --seconds <≥ delta/0.1>`（**閉じる向きで近づく**）。b は A2 の閉じる向きの誤差の平均（tick を rad に）で、**最初は b = 0 と b = A2 の平均の 2 通り**（各 3 回） | **閉じる向きの小さい誤差（約 3 tick の見込み。W3.5 の実績）で、目標に寄せられるか**。`send_joint_delta.py` の目標は実測からの相対なので、**絶対の目標 G に対する最終誤差**を見る |
| B3 | B1・B2 で有望な方法を、lift と wrist_flex にも、5 回ずつ | 再現性（Q-B）と、向きによる差（Q-C） |

- B 系列の各到達の前に、**G の誤差の実測から delta を計算する式（B1・B2）は、ユーザーの電卓または Claude の計算で、実行の前に確認する**（その場で計算したら、値を読み上げて確認してから送る）。
- **床**: B2 の「いったん開く」は先端が上がる向き（安全）。B1 の k = 2 で elbow が戻りすぎて **閉じる向き（+）に動く**ことはない（delta は常に − 向き）。**+ に動く指令（B2 の 2 段目）は、delta の大きさが |G − m2| + b ≒ 0.04 rad 以内で、先端の下がりが 0.04 × 124 ≒ 5 mm 以内**。順運動学の z ≥ 0.050 を事前に確認する。

### 結果の整理（Claude が、記録を受け取ってから。リポジトリの外の計算）

- 関節ごとに、G との差（tick）の平均・標準偏差・範囲を、向き（開く・閉じる）ごとに。先端（順運動学。mm）の x・y・z の平均・標準偏差・範囲。tf との突き合わせ。
- **手前止まり（開く向き）**: 平均が、W1 の 17 tick（1 サンプル）・旧校正の W3.5 の 27 tick（出典: inventory）と同程度か。標準偏差が、補償の限界。
- 閉じる向きの差と、開く向きの差の **差**（ヒステリシス）。5 秒後と 15 秒後の差（クリープ）。
- B 系列: 最終誤差（絶対目標 G に対する tick、mm）と、A 系列の同じ向きの値との比較。**「ずらした目標」が A のばらつきの範囲に入るか**。
- 結果から、D-2 ＋ 接近方向の統一で**目的（先端で数 mm 以下）を満たせるか**、D-1 の要否を判断する材料にする（D-3 は最後）。

## 6. 規則との対応・リスク

- 実機（サーボ）を動かすのはユーザーだけ。この計画の実行は承認後。モック・ビルドは許可があるまで行わない（**手順書 `accuracy_check.md` を書くのは docs だけで、ビルド不要**）。
- **リスク（事実と推測）**: lift・elbow の + への動きは先端が下がる（計算）。手前止まりの量は姿勢で変わるので、順運動学の z の事前確認を毎回。長時間の往復でサーボが熱くなる（**温度は監視していない**。触って確認。`[diag]` は起動時だけ）。MoveIt の目標が `<current>` に戻る件（残課題）は、Plan のアニメーションで必ず確認。
- **この測定の限界**: G の近く（T の付近）の 1 姿勢だけ。**姿勢で摩擦・重力の向きが変わる**（T で wrist_flex の重力はほぼ 0、出発点では + 向き）ので、結果を別の姿勢に広げるときは再測定が要る。N = 5 は小さい（標準偏差は粗い見積もり）。
